# 🎙️ Voice-Based Note Taker

A simple Python-based voice-controlled note-taking app that lets users create, save, and manage notes using speech commands.

## 🚀 Features

- 🎤 Convert speech to text using your microphone
- 📝 Save dictated notes to local `.txt` files
- 📁 Automatically names files based on timestamps or keywords
- 🔊 Optional text-to-speech feedback
- 🧠 Lightweight and beginner-friendly

## 🧰 Technologies Used

- Python 3.x
- SpeechRecognition
- PyAudio
## 📚 How It Works

1. Listens to your voice via the system's microphone.
2. Converts audio to text using Google Web Speech API.
3. Saves the recognized text into a `.txt` file.
4. Optionally speaks back the note for confirmation.
